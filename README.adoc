= kdl-d

Native https://kdl.dev/[KDL] document language parser and writer for the D programming language.

link:https://github.com/dlang-supplemental/kdl-d/issues[Report Bug] ·
link:https://github.com/dlang-supplemental/kdl-d/issues[Request Feature]

Package name on DUB: `kdl`.

== About The Project

KDL is a node-oriented document language (XML-like semantics, CLI-ish syntax). This library provides a DOM API plus `parseKdl` / `writeKdl` with hybrid **KDL 1.0** and **KDL 2.0** support.

No prior DUB package shipped a dedicated KDL implementation for D (`newsdlang` dropped earlier KDL plans).

== Features

* Document / node / argument / property / type-annotation DOM
* Hybrid parse: prefer KDL 2.0, fall back to KDL 1.0; honor `/- kdl-version N`
* Slashdash comments (`/-`), `//` and nested `/* */` comments
* Writer with v1 or v2 keyword forms (`true` vs `#true`, …)
* Zero dependencies beyond Phobos

== Usage

[source,d]
----
import kdl;

void main()
{
    auto doc = parseKdl(`
        title "Hello KDL"
        person name="Ada" age=36 {
            interest "math"
        }
    `);

    assert(doc.node("title").arguments[0].asString == "Hello KDL");
    assert(doc.node("person").property("name").value.asString == "Ada");

    import std.stdio : writeln;
    writeln(writeKdl(doc));
}
----

Force a dialect:

[source,d]
----
auto v2 = parseKdl(`flags enabled=#true`, KdlVersion.v2);
auto v1 = parseKdl(`flags enabled=true`, KdlVersion.v1);
----

== Installation

Add to `dub.json`:

[source,json]
----
"dependencies": {
    "kdl": "~>0.1.0"
}
----

Or `dub.sdl`:

[source,sdl]
----
dependency "kdl" version="~>0.1.0"
----
